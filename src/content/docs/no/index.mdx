BibTeX er den klassiske løsningen for referanser i LaTeX. Kilder lagres i en `.bib`-fil, siteres med nøkler og formateres med valgt stil.

## What is BibTeX?

BibTeX is a bibliography processor in the LaTeX toolchain. You keep references in a plain-text `.bib` file and cite them in your document using citation keys.

## Minimal Working Example

```bibtex
@book{Hemingway1952,
  title     = {The Old Man and the Sea},
  author    = {Hemingway, Ernest},
  year      = {1952},
  publisher = {Charles Scribner's Sons}
}
```

```latex
\documentclass{article}
\begin{document}
Example citation: \cite{Hemingway1952}.
\bibliographystyle{plain}
\bibliography{references}
\end{document}
```

## Quick Start

1. Create `references.bib`.
2. Add references with complete metadata.
3. Cite in LaTeX with `\cite{...}`.
4. Compile with either `latex -> bibtex -> latex -> latex` or `latex -> biber -> latex -> latex`.

## Common Mistakes

- Missing commas/braces in `.bib`.
- Duplicate citation keys.
- Missing required fields.
- Wrong compile order.

## Slik fungerer BibTeX

1. Legg inn poster i en `.bib`-fil.
2. Siter med nøkler, for eksempel `\cite{Hemingway1952}`.
3. Kompiler med LaTeX/BibTeX for å generere litteraturlisten.

## Begrensninger ved manuell håndtering

- Små syntaksfeil kan stoppe kompilering.
- Store bibliografier er krevende å vedlikeholde manuelt.
- Teamarbeid skaper ofte duplikater og nøkkelkonflikter.

## BibTeX vs BibLaTeX og Biber

BibTeX er fortsatt mye brukt, spesielt når maler krever `.bst`-stiler. BibLaTeX med Biber gir mer fleksibilitet, bedre Unicode-støtte og sterkere lokaliseringskontroll.
