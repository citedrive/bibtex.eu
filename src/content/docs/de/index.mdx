BibTeX ist der klassische Standard zur Literaturverwaltung in LaTeX. Referenzen werden in einer `.bib`-Datei gespeichert, über Zitierschlüssel referenziert und mit einer `.bst`-Stildatei formatiert.

Diese Seite ist ein praktischer Schnellstart für Einsteiger und eine kompakte Referenz für Fortgeschrittene.

## Was ist BibTeX?

BibTeX ist ein Literaturprozessor in der LaTeX-Toolchain. Quellen liegen in einer `.bib`-Datenbank, Zitate werden über Schlüssel im `.tex`-Dokument gesetzt, und die Bibliografie wird beim Kompilieren erzeugt.

## Minimales Beispiel

### Beispiel `.bib`-Eintrag

```bibtex
@book{Hemingway1952,
  title     = {The Old Man and the Sea},
  author    = {Hemingway, Ernest},
  year      = {1952},
  publisher = {Charles Scribner's Sons}
}
```

### Beispiel in LaTeX

```latex
\documentclass{article}
\begin{document}
Beispielzitat: \cite{Hemingway1952}.
\bibliographystyle{plain}
\bibliography{references}
\end{document}
```

## Schnellstart

1. `references.bib` erstellen.
2. Referenzen vollständig eintragen.
3. Im Text mit Schlüsseln zitieren (`\cite{...}`).
4. Kompilieren:
   - BibTeX: `latex -> bibtex -> latex -> latex`
   - Biber: `latex -> biber -> latex -> latex`

## Häufige Fehler

- Fehlende Kommas oder Klammern in `.bib`.
- Doppelte Zitierschlüssel.
- Unvollständige Felder.
- Falsche Kompilierreihenfolge.

## Grenzen manueller BibTeX-Workflows

- Manuelles `.bib`-Editing ist fehleranfällig.
- Formatierung und Debugging kosten Zeit.
- Synchronisierung zwischen Tools ist oft manuell.
- Zusammenarbeit erhöht Risiko für Duplikate und Konflikte.

## BibTeX vs. BibLaTeX und Biber

BibTeX bleibt wichtig, besonders bei `.bst`-Vorgaben. BibLaTeX mit Biber ist flexibler bei Unicode, Mehrsprachigkeit und Sortierung.
