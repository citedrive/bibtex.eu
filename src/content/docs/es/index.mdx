BibTeX es el sistema clásico para gestionar referencias en LaTeX. Guarda los datos en un archivo `.bib`, usa claves de cita y genera la bibliografía con un estilo.

Esta página es una guía práctica de inicio rápido para principiantes y usuarios avanzados.

## ¿Qué es BibTeX?

BibTeX es un procesador bibliográfico para LaTeX. Guarda referencias en un archivo `.bib`, las cita por clave y genera automáticamente la bibliografía.

## Ejemplo mínimo funcional

### Entrada `.bib`

```bibtex
@book{Hemingway1952,
  title     = {The Old Man and the Sea},
  author    = {Hemingway, Ernest},
  year      = {1952},
  publisher = {Charles Scribner's Sons}
}
```

### Uso en LaTeX

```latex
\documentclass{article}
\begin{document}
Cita de ejemplo: \cite{Hemingway1952}.
\bibliographystyle{plain}
\bibliography{references}
\end{document}
```

## Inicio rápido

1. Crea `references.bib`.
2. Añade referencias completas.
3. Cita en LaTeX con `\cite{...}`.
4. Compila:
   - BibTeX: `latex -> bibtex -> latex -> latex`
   - Biber: `latex -> biber -> latex -> latex`

## Errores comunes

- Falta de comas o llaves en `.bib`.
- Claves de cita duplicadas.
- Campos obligatorios incompletos.
- Secuencia de compilación incorrecta.

## Límites del flujo manual con BibTeX

- Editar `.bib` manualmente es propenso a errores.
- Formatear y depurar consume tiempo.
- La sincronización entre herramientas suele ser manual.
- Colaborar complica control de duplicados y claves.

## BibTeX vs BibLaTeX y Biber

BibTeX sigue siendo útil, sobre todo con plantillas que exigen `.bst`. BibLaTeX con Biber ofrece más flexibilidad para Unicode, ordenación y localización.
