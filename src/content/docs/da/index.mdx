BibTeX er standardløsningen til referencer i LaTeX. Kilder gemmes i en `.bib`-fil, citeres via nøgler og formatteres med en bibliografistil.

## What is BibTeX?

BibTeX is a bibliography processor in the LaTeX toolchain. You keep references in a plain-text `.bib` file and cite them in your document using citation keys.

## Minimal Working Example

```bibtex
@book{Hemingway1952,
  title     = {The Old Man and the Sea},
  author    = {Hemingway, Ernest},
  year      = {1952},
  publisher = {Charles Scribner's Sons}
}
```

```latex
\documentclass{article}
\begin{document}
Example citation: \cite{Hemingway1952}.
\bibliographystyle{plain}
\bibliography{references}
\end{document}
```

## Quick Start

1. Create `references.bib`.
2. Add references with complete metadata.
3. Cite in LaTeX with `\cite{...}`.
4. Compile with either `latex -> bibtex -> latex -> latex` or `latex -> biber -> latex -> latex`.

## Common Mistakes

- Missing commas/braces in `.bib`.
- Duplicate citation keys.
- Missing required fields.
- Wrong compile order.

## Sådan virker BibTeX

1. Opret poster i en `.bib`-fil.
2. Citér med nøgler, fx `\cite{Hemingway1952}`.
3. Kompilér med LaTeX/BibTeX for at generere litteraturlisten.

## Begrænsninger ved manuel håndtering

- Små syntaksfejl kan stoppe kompilering.
- Store bibliografier er svære at holde konsistente.
- Teamarbejde giver ofte dubletter og nøglekonflikter.

## BibTeX vs BibLaTeX og Biber

BibTeX bruges stadig bredt, især når skabeloner kræver `.bst`-stile. BibLaTeX med Biber giver mere fleksibilitet, bedre Unicode-støtte og stærkere lokaliseringsmuligheder.
