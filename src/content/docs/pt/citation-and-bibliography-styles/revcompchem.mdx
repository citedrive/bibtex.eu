## Uso geral do estilo **revcompchem**

O estilo **revcompchem** é um ficheiro BibTeX `.bst`. Define a ordenação, rótulos e pontuação da sua bibliografia quando usado com uma base `.bib`. Abaixo há um resumo dos estilos BibTeX, depois como usar **revcompchem** no **Overleaf** e como o **CiteDrive** alinha BibTeX e BibLaTeX com o Overleaf.

O BibTeX é uma ferramenta bibliográfica poderosa usada para criar bibliografias em documentos LaTeX. É uma das ferramentas bibliográficas mais utilizadas e suporta muitos estilos de bibliografia e formatos de citação diferentes.

Embora o Overleaf atualmente não suporte todos os estilos de bibliografia compatíveis com o BibTeX, muitos estilos de bibliografia estão incluídos na biblioteca de estilos de bibliografia BibTeX. Esses estilos de bibliografia incluem formatos de citação APA, IEEE, CSE e Chicago. Você também pode usar estilos de bibliografia personalizados criando seu próprio arquivo de formato de bibliografia bibtex ou importando um de outra fonte.

Seja usando BibTeX por conta própria ou através do Overleaf, é uma ferramenta essencial para criar bibliografias em documentos científicos e técnicos. Para saber mais sobre gerenciamento de bibliografias com bibtex e Overleaf, visite bibtex.eu ou nossa documentação!

## Usar o estilo **revcompchem** no Overleaf

É possível utilizar o estilo de bibliografia **revcompchem** BibTeX no Overleaf?

A resposta é sim! O estilo de bibliografia **revcompchem** é um dos muitos estilos integrados no Overleaf. Use este estilo digitando **`\bibliographystyle{revcompchem}`** no seu documento tex, ou use o exemplo a seguir para um novo documento no Overleaf:

```latex
\documentclass{article}
  \usepackage[utf8]{inputenc}

  \title{Um exemplo LaTeX de referências BibTeX usando o estilo de bibliografia revcompchem.}
  \author{John Smith}

  \begin{document}

  \maketitle

  Estudos recentes demonstraram que LaTeX é uma excelente ferramenta para a criação de documentos acadêmicos \cite{Smith2023}.

  \medskip

  \bibliographystyle{revcompchem} % aqui carrega revcompchem.bst
  \bibliography{bibliography}

\end{document}
```
