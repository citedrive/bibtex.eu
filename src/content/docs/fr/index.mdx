BibTeX est le système historique de gestion bibliographique pour LaTeX. Les références sont stockées dans un fichier `.bib`, appelées via des clés de citation, puis formatées selon un style.

Cette page est un guide de démarrage rapide utile pour débutants et utilisateurs avancés.

## Qu'est-ce que BibTeX ?

BibTeX est un processeur bibliographique pour LaTeX. Les sources sont stockées dans un fichier `.bib`, citées via des clés, puis formatées automatiquement.

## Exemple minimal fonctionnel

### Entrée `.bib`

```bibtex
@book{Hemingway1952,
  title     = {The Old Man and the Sea},
  author    = {Hemingway, Ernest},
  year      = {1952},
  publisher = {Charles Scribner's Sons}
}
```

### Utilisation dans LaTeX

```latex
\documentclass{article}
\begin{document}
Exemple de citation : \cite{Hemingway1952}.
\bibliographystyle{plain}
\bibliography{references}
\end{document}
```

## Démarrage rapide

1. Créez `references.bib`.
2. Ajoutez vos références.
3. Citez dans LaTeX avec `\cite{...}`.
4. Compilez :
   - BibTeX : `latex -> bibtex -> latex -> latex`
   - Biber : `latex -> biber -> latex -> latex`

## Erreurs fréquentes

- Virgules ou accolades manquantes.
- Clés de citation dupliquées.
- Champs obligatoires incomplets.
- Mauvais ordre de compilation.

## Limites d'un flux BibTeX manuel

- Édition `.bib` sujette aux erreurs.
- Débogage et formatage chronophages.
- Synchronisation manuelle entre outils.
- Collaboration plus difficile.

## BibTeX vs BibLaTeX et Biber

BibTeX reste courant, surtout avec des styles `.bst` imposés. BibLaTeX/Biber offre plus de flexibilité (Unicode, tri, localisation).
